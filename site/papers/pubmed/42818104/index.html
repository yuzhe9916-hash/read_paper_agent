Auto-SMART: a web-based platform for repair-template design for CRISPR/Cas9 homology-directed editing.

Zhao, Chuanping; Cao, Yan; Martemyanov, Kirill A
bioRxiv : the preprint server for biology · 2026-10-01 · 全文(pmc) · 原文

该文介绍Auto-SMART网络平台，用于设计CRISPR/Cas9同源定向修复的供体模板，通过沉默突变优化切割位点与编辑位点间距；虽涉及Cas9切割与HDR修复模板设计，但侧重工具应用而非分子机制研究，故评分为5。

摘要

Genome engineering via CRISPR/Cas9 has been widely applied in biological research and developing gene therapies. However, genome editing flexibility is strongly constrained by the position and quality of guide RNAs relative to the intended edit: desired edit sites are frequently positioned far from efficient protospacer adjacent motifs (PAM). SMART (Silently Mutate And Repair Template) technique relaxes this constraint by silently mutating the gap between the Cas9 cut and the edit in the repair donor, preserving the encoded protein while expanding the usable guide-RNA design space. Designing such donors manually requires coordinated reasoning over transcript structure, reading frame, candidate protospacers, codon usage, homology arms and the expected edited allele. Auto-SMART is a web platform that automates this process for CRISPR/Cas9-mediated insertion, deletion, point mutation and sequence replacement in coding exons and in introns. Users choose a genome assembly, search a gene symbol or transcript, select a modification site and select an editing operation. Auto-SMART finds nearby Streptococcus pyogenes Cas9 (SpCas9) guides, ranks them by predicted on-target activity and cut-to-edit geometry, builds repair templates with synonymous substitutions, automatically recodes residual on-target sites to prevent re-cutting and renders interpretable panels for the target locus, donor template and locus after HDR, together with a downloadable report and a Primer3 genotyping handoff. The web application for Auto-SMART is freely available at https://auto-smart.chuanping.org/ .

摘要翻译

通过CRISPR/Cas9进行的基因组工程已广泛应用于生物学研究和基因治疗开发中。然而，基因组编辑的灵活性受到引导RNA相对于预期编辑位点的位置和质量的强烈限制：理想的编辑位点往往距离高效的原间隔区邻近基序（PAM）较远。SMART（沉默突变并修复模板）技术通过在不改变编码蛋白的前提下，对修复供体中Cas9切割位点与编辑位点之间的间隔进行沉默突变，从而放宽了这一限制，同时扩展了可用的引导RNA设计空间。手动设计此类供体需要对转录本结构、阅读框、候选原间隔区、密码子使用、同源臂以及预期编辑后的等位基因进行协调推理。Auto-SMART是一个网络平台，可自动化这一过程，适用于CRISPR/Cas9介导的编码外显子和内含子中的插入、删除、点突变和序列替换。用户选择基因组组装版本，搜索基因符号或转录本，选择修饰位点并选择编辑操作。Auto-SMART会寻找附近的化脓性链球菌Cas9（SpCas9）引导序列，根据预测的靶向活性和切割到编辑的几何结构进行排序，构建带有同义替换的修复模板，自动重新编码残留的靶向位点以防止再切割，并为目标位点、供体模板和HDR后的位点生成可解释的图谱，同时提供可下载的报告和Primer3基因分型交接文件。Auto-SMART的Web应用程序可免费访问，网址为https://auto-smart.chuanping.org/。

03 研究问题

  • 具体问题：CRISPR/Cas9 介导的 HDR 编辑中，目标编辑位点常常远离高效的 PAM 序列，导致可用的 guide RNA 选择受限；同时，Cas9 切割后若修复供体保留原始靶序列，可能被再次切割（re-cutting），降低 HDR 效率。
  • 为什么重要：基因组编辑的灵活性直接受 guide RNA 位置和质量约束。若编辑位点附近缺乏合适 PAM，则无法使用 SpCas9 进行高效编辑，限制了基因治疗和基础研究的应用范围。
  • 现有方法为何不足：手动设计 SMART 供体需要协调推理转录本结构、阅读框、候选 protospacer、密码子使用、同源臂和预期编辑后等位基因，过程繁琐且易出错，缺乏自动化工具。
  • 精确研究问题：Can a web-based platform automatically design repair templates that silently mutate the Cas9 cut-to-edit gap, thereby expanding the usable guide-RNA design space while preserving the encoded protein?

06 核心思想

1) 表面方法

Auto-SMART 是一个 web 平台，用户选择基因组组装、搜索基因符号或转录本、选择修饰位点和编辑操作（插入、删除、点突变、序列替换），平台自动完成以下流程：找到附近 SpCas9 guide → 按预测 on-target 活性和切割-编辑几何关系排序 → 构建含同义替换的修复模板 → 自动重编码残余 on-target 位点防止 re-cutting → 渲染靶位点、供体模板和 HDR 后位点的可视化面板 → 输出可下载报告和 Primer3 genotyping 交接。

2) 核心洞察

SMART 策略的核心洞察是：通过同义突变沉默 Cas9 切割位点与编辑位点之间的间隔序列，可以在不改变编码蛋白的前提下，使原本因 PAM 位置不佳而不可用的 guide RNA 变得可用。这本质上是将「编辑位点必须靠近 PAM」的刚性约束，转化为「切割位点与编辑位点之间的间隔序列可被灵活调整」的软约束。

3) 可能的普适教训 [Analysis]

  • 约束转化：将刚性空间约束（编辑位点必须靠近 PAM）转化为可调参数（间隔序列可同义突变），是扩大设计空间的一般策略。本课题中，stagger-cleavage 机制 产生的交错切口同样存在「切割位点与编辑位点间隔」问题，可借鉴此思路。
  • 自动化多约束协调：将转录本结构、阅读框、密码子使用、同源臂等多层面约束自动化协调，是工具类方法的核心价值。

  1. SMART 策略的核心逻辑：通过同义突变沉默 Cas9 切割位点与编辑位点之间的间隔序列，可在不改变蛋白序列的前提下扩大 guide RNA 设计空间。迁移到本课题：在 stagger-cleavage（交错切割）机制 研究中，Cas9 切割产生的交错切口（通常为 1-3 nt 突出端）同样存在「切割位点与编辑位点间隔」问题。可借鉴 SMART 思路，通过同义突变调整间隔序列，使交错切割产生的切口位置更有利于 HDR 或碱基编辑。

  2. 约束转化思想：将「编辑位点必须靠近 PAM」的刚性约束转化为「间隔序列可调」的软约束。迁移到本课题：在 碱基编辑（base editing） 中，编辑窗口（通常为 protospacer 的 4-8 位）受 PAM 位置限制。可借鉴此思路，通过同义突变调整编辑窗口内的序列，使碱基编辑器可作用于目标位点。

  3. Re-coding 防止 re-cutting：自动重编码残余 on-target 位点，防止修复供体被 Cas9 再次切割。迁移到本课题：在 HDR 实验中，供体模板若保留原始靶序列，可能被 Cas9 再次切割。此策略可直接应用于任何 HDR 实验设计。

  4. 多约束自动化协调：将转录本结构、阅读框、密码子使用、同源臂等多层面约束自动化。迁移到本课题：在设计碱基编辑或 HDR 实验时，可开发类似工具自动化处理多约束条件。

  5. Web 平台的可及性：将复杂设计流程封装为 web 应用，降低使用门槛。迁移到本课题：可考虑将 stagger-cleavage 分析或碱基编辑设计工具封装为类似平台。

15 与已有知识连接

  • CRISPR/Cas9 HDR 机制：HDR 依赖同源臂和供体模板，Cas9 切割产生 DSB 后通过 HDR 修复。本文的 SMART 策略是对 HDR 供体设计的优化，与经典 HDR 机制一致（经外部核验：HDR 是 CRISPR 编辑的主要修复途径之一）。
  • SMART 策略：本文是 SMART 策略的自动化实现。SMART 最初由 Martemyanov 实验室提出（作者之一），本文是其 web 化工具（作者主张，基于作者列表推断 [Analysis]）。
  • Stagger-cleavage 机制：Cas9 切割产生平末端或交错切口（取决于 guide RNA 和靶序列）。本文的「切割-编辑几何关系」排序直接涉及切割位点与编辑位点的空间关系，与 stagger-cleavage 机制相关（经外部核验：Cas9 切割通常产生平末端，但某些情况下可产生交错切口）。
  • 碱基编辑：碱基编辑器（如 BE4、ABE）不依赖 DSB 和 HDR，但受编辑窗口和 PAM 限制。Auto-SMART 的 HDR 方案可作为碱基编辑的互补工具（经外部核验：碱基编辑与 HDR 是两种互补的编辑策略）。
  • Guide RNA 设计工具：与 CRISPOR、Benchling 等工具相比，Auto-SMART 的独特之处在于集成 SMART 策略和 re-coding 功能（作者主张，基于摘要描述 [Analysis]）。

  • 验证方式：比较不同切割模式下，stagger-aware 模板与标准模板的 HDR 效率
  • 可能的失败模式：切割模式预测不准确；交错切口对 HDR 的影响可能小于预期
  • 创新状态：unverified

Reviewer

  • Overall assessment The abstract describes a potentially useful web tool that addresses a real bottleneck in CRISPR/Cas9 homology-directed repair (HDR) template design. The conceptual contribution, automating the SMART technique, is sensible and could be of practical value to the genome engineering community. However, the abstract provides no evidence that the platform actually works as described. There is no validation data, no benchmark comparison, no experimental confirmation, and no technical detail that would allow a reader to assess correctness, reliability, or usability. As presented, this is a software announcement rather than a scientific contribution with demonstrated performance. The case for the platform's utility and correctness is not established from the supplied material.
  • Who would be interested in the results, and why Molecular biologists, genome engineers, and researchers using CRISPR/Cas9 for precise editing in model organisms or cell lines would be interested. The tool addresses a practical pain point: the constraint imposed by PAM availability relative to the desired edit site. Laboratories performing knock-in experiments, especially those working with difficult loci, would benefit from automated design of repair templates with silent mutations. The web-based, freely accessible format also lowers the barrier for non-specialist labs.
  • Major strengths The problem addressed is real and well-recognized in the genome engineering field. The SMART concept, as described, is elegant and practical. The platform appears to integrate multiple design steps (guide selection, template construction, re-cutting avoidance, genotyping handoff) into a single automated workflow, which is a genuine convenience.
